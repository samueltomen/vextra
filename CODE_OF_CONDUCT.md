# Code de conduite

Nous voulons une communauté ouverte et respectueuse, quels que soient
l'expérience, l'origine ou l'identité de chacun.

## Nos engagements

- Être courtois et constructif, y compris dans le désaccord.
- Critiquer le code et les idées, jamais les personnes.
- Accueillir les nouveaux venus et rester patient avec les questions.
- Respecter la vie privée : ne publiez ni donnée personnelle ni secret.

## Comportements inacceptables

Harcèlement, insultes, discriminations, attaques personnelles, spam, publication
d'informations privées sans accord.

## Application

Les mainteneurs peuvent modifier, masquer ou supprimer tout commentaire, issue ou
contribution contraire à ce code, et restreindre l'accès de leurs auteurs.

Pour signaler un comportement problématique, contactez les mainteneurs par un
message privé GitHub ou, pour un sujet de sécurité, via [SECURITY.md](SECURITY.md).

Ce texte s'inspire du Contributor Covenant.
